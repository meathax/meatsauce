At1799 the only work-RAM difference is CPU address0x20ff3, native0x92 versus
MAME0x8e. The retained bytes at0x20fee decode as SR0x2004 followed by
PC0x00009e92 versus0x00009e8e, followed at0x20ff4 by identical0x00009dde.
Pinned ROM and official MAME unidasm show `TST.B ($4,A6)` at0x9e8e and
`BEQ $9e8e` at0x9e92; the JSR at0x9dd8 has return0x9dde after setting
A7 to0x20ff8. This is consistent with a retained normal six-byte exception
frame above a JSR return, with PCs at adjacent wait-loop boundaries.
The manufacturer specifies this SR/PC layout in section6.2.4/Figure6-5 of
[MC68000UM](https://www.nxp.com/docs/en/reference-manual/MC68000UM.pdf).
