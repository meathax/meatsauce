# Physical 8080 interrupt acceptance

Intel's September1975 8080 manual establishes an enabled request in phi2 of the last instruction state. The asynchronous INT input is reclocked internally; Figure2-8 shows the stored request changing within the phi2 high interval. The next M1 publishes INTA in the SYNC status word, preserves PC without incrementing it, and receives the external instruction in T3. This establishes ordering, not a Sheriff absolute origin. Primary: printed2-11/PDF24, Figure2-8; retained scan SHA d5982f96536b1dbecbeff409d2370970638716296dce7b318624d86221597a9e.

READY is tested in phi2 of T2/TW. The manual requires its setup before phi2 falls to leave TW, and the cycle advances at the following phi1 rise. Thus waits can postpone the final instruction state and the eligible interrupt boundary. Primary: printed2-5/PDF18. Neither page supplies a measured Sheriff edge or the exact AC acceptance aperture for its CPU revision.

The current adapter uses phase0..4 for f1 and phase8..19 for f2, with a25-master cycle. `rtl/n8080_vm80a_ce.v:494` captures INT throughout f2; :495 captures the machine-start condition. The following f1 condition at :511 qualifies INTA from stored INT, INTE, reset/hold and instruction-end/halt terms. The later clear at :512 has priority. EI/DI and INTE clearing are at :516-517. READY selects TW/T3 at :416-417, with DAD internal-ready handling at :271-272. These storage steps are a source implementation of the manufacturer ordering; the internal RTL latch names are not physical CPU measurements.
