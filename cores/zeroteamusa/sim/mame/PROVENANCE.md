# Capture helper provenance

Adapted from the installed mister-arcade-core skill assets, `assets/core/scripts/mame/capture.lua` and `run.lua`. The run helper is unchanged; the capture helper adds an optional Zero Team read-only export of the buffered sprite save item. The local play helper supplies physical input fields and observes COP, sound, distance and optional stateful collision operations without writing emulated RAM or registers. Original headers are retained. The skill asset license is GPL-3.0-or-later; exact local helper hashes are recorded with each capture.
